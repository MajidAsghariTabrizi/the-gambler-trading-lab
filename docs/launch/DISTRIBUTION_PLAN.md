# Distribution plan (realistic, no spam)

1. Owner submits Show HN personally (draft ready: docs/launch/SHOW_HN.md). One submission, no vote manipulation.
2. Owner posts LinkedIn announcement (docs/launch/LINKEDIN.md) with the social preview image.
3. Publish the technical article on a personal blog/dev.to, cross-linked from the repo.
4. Share the three short posts across a week (docs/launch/SHORT_POSTS.md) — no mass-DMing, no astroturfing.
5. Submit to relevant link aggregators ONLY where the owner is a member (r/algotrading weekly thread, quant forums) with disclosure that it is one's own project.
6. Add the repo URL to the author's GitHub profile and pinned.
7. Let the three starter issues invite real contributions.

Do not: buy stars, automate submissions, spam communities, or promise profitability.
