# Contributing to The Gambler

Research software. No real-order features will ever be merged.

Wanted areas
- Market-data adapters (read-only)
- Execution simulation realism (queue bounds, partial fills)
- Scientific validation (leakage, purge, day-block stats)
- Decimal accounting precision
- Deterministic offline tests and docs

Workflow: fork, branch, add tests, run `pytest -q tests`, PR with description and evidence.
